Download GitHub Code Quality license usage as a CSV
You can now download a CSV report of your GitHub Code Quality license usage to reconcile your license count with your own records.
The report includes:
Each active committer who consumes a Code Quality license.
The repositories that received their commits in the last 90 days.
Whether each committer is unique to a single repository or organization.
Use the unique committer details to identify where disabling Code Quality could free up licenses for the next billing period without changing your current license charge.
To download your report, go to the Billing and licensing page in your organization or enterprise, open Licensing , and download the CSV from the Code Quality card.
CSV downloads are available on GitHub Team and GitHub Enterprise Cloud.
For details, see Viewing and managing GitHub Code Quality costs .
