Email notifications for repository push events have been retired
As of October 15, 2026, email notifications for repository push events have been retired and are no longer sent.
We shut down this feature to help prevent spam and abuse. Because recipients didn’t have to consent before receiving these emails, the feature could be misused to send unwanted messages through GitHub’s email infrastructure.
To continue sending email notifications for repository push events, you can use a GitHub Actions workflow triggered by push events to send emails through your own SMTP server or email provider.
