# Video-script drafting task

Write one 3–5 minute Markdown video script per brief. Use the same factual claims and claim IDs as the article, preserving each as `<!-- claim:01-c1 -->`. Include narration, useful visual directions, an AI-assistance disclosure, and description-ready source notes with timestamps. Optimize for listening rather than reading aloud from the article. Do not add factual claims not present in the brief. End with the article-link placeholder and a concrete watch item for the next edition.
