# Source independence notes

- GitHub Changelog and GitHub's YouTube channel are two formats from the same underlying organization. They do not independently corroborate one GitHub claim even though their configured publisher IDs preserve collection-route coverage. Editorial review must reconcile matching recordings and announcements.
- Google Developers Blog and Google for Developers YouTube are likewise treated as one interested organization when they support the same claim.
- Simon Willison is an independent practitioner source relative to the platform vendors.
- Practical AI and Latent Space are separate podcast producers, but individual guests can introduce overlap with a vendor. Guest affiliation must be checked claim by claim.
- Syndicated stories, reposts, and a podcast's video upload count once. Stable URLs/native IDs and human reconciliation prevent format changes from inflating corroboration.

The configured list supplies discovery routes, not automatic credibility. A submitted live run must document which six publishers remain independent at the claim level and must disclose missing perspectives.
